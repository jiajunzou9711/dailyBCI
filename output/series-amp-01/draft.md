起于 2026-09-10。承 series-grounding-02（参考电极与地电极）。

## 本期范围与主线

核心问题：脑电采集系统要做到什么，才能把头皮上那个电压差准确地记录下来？

用户 2026-09-10 定下的五段主线，严格按此展开。卡数不限，但每段只讲该段的事。

### ① 目标：尽量准确地记录两处头皮的电压差

- 测量电极与参考电极共同确定记录内容。
- 本期关心的是：这个差值经过采集系统后，能否被保留。

### ② 接上仪器本身就可能改变读到的电压

- 电极接触阻抗与放大器输入阻抗形成分压，输入端拿到的电压变小。
- 由此引出高输入阻抗。
- 解释为什么要到 GΩ 量级，以及这个要求取决于哪些条件。

### ③ 电压进入仪器后还要减少共同干扰

- 引出差分放大：放大两端之差，抑制两端共同的变化。
- 说明它为什么适合脑电。
- 交代它只依据两端电压关系工作，无法识别某个成分的生理来源。

### ④ 电极接触不一致会削弱这种抑制

- 两端相同的干扰经过不同的电极阻抗后，在放大器输入端形成差异。
- 这部分差异同样被放大。
- 由此把电极接触、高输入阻抗、差分放大三者连起来。

### ⑤ 回到采集：准确记录需要电极与放大器共同满足条件

- 高输入阻抗帮助保留电压。
- 差分放大帮助抑制共同干扰。
- 良好且稳定的电极接触，让这两项能力在实际记录中发挥作用。

### 最终回答

更好的脑电采集，需要同时减少接入仪器造成的信号损失，以及干扰进入记录的机会。

### 全篇约束

- 场景固定在头皮 EEG、湿 Ag/AgCl 电极接差分放大器，与 series-grounding-02 一致。
- 表达平实，每段只推进一个必要信息。
- Less is more：与本期主线无关的内容一律不引入。

## 已定稿

### ① 记录的目标是把头皮上的电压差原样搬进文件

脑电采集要做的事，是记录头皮上两点之间的电压差。

一个通道对应两片电极：测量电极与参考电极（reference electrode）。通道记录的电压，等于测量位置的电位减去参考位置的电位，头皮上测到的幅度在 10 µV 到 100 µV 之间，随节律与状态变化¹。

由此，「准确」有两条具体要求：**幅度不能变，也不能混进别的东西。**

电极接上放大器的那一刻，这两条都不自动成立。


### ②-1 接上放大器，读到的电压就变小了

要读出头皮上的电压，得先把电极接到放大器。这一接，读到的电压就比头皮上的小。

原因在于放大器读电压时，输入端有电流流过。这股电流由整条回路决定：

```
I = V / (R_e + Z_in)
```

R_e 是电极与皮肤的接触阻抗（electrode–skin contact impedance），Z_in 是放大器的输入阻抗（input impedance）。

电流流过 R_e 会产生压降 I·R_e。这部分电压落在电极上，进不了放大器。放大器读到的是剩下的：

```
V_读到 = V − I·R_e = V × Z_in/(R_e + Z_in)
```

Z_in 出现在分母里。**Z_in 越大，I 越小；I 越小，R_e 上的压降越小，读数越接近 V。**

配图：回路图，V_头皮 经 R_e 串到 Z_in，标出 I 与 R_e 上的压降。



### ②-2 Z_in 要大到什么程度

上一步的式子可以换个角度读。被扣掉的那部分占多大比例：

```
误差 = I·R_e / V = R_e / (R_e + Z_in)
```

当 Z_in 远大于 R_e 时，这个比例约等于 **R_e 与 Z_in 之比**。取 0.1% 作为示例的容忍度，Z_in 至少要是 R_e 的一千倍。

代入头皮实测的接触阻抗²：凝胶电极 14 kΩ，干电极 516 kΩ。

```
凝胶电极 14 kΩ   → Z_in 需 > 14 MΩ
干电极  516 kΩ   → Z_in 需 > 516 MΩ
```

商用设备正落在这个量级：g.USBamp 标称输入阻抗 > 1000 GΩ³。

**GΩ 这个要求由两件事决定：电极的接触阻抗有多大，以及你允许多大的幅度误差。**

（0.1% 为示例值，卡上就地写明；两个「需 >」为自算，卡上注明。）



### ③-1 差分放大只放大两端之差

卡 ② 处理的是「幅度不能变」。接下来处理另一条：不能混进别的东西。

干扰进入记录的方式有一个特点——它同时出现在两片电极上，两边的量相差不多。市电在体表造成的电位起伏就是这样，头上每片电极都被同一份起伏抬起。

差分放大器（differential amplifier）的输出只取决于两个输入端的差，G 为增益：

```
输出 = G · (V₊ − V₋)
```

两端共有的那部分在相减时抵消，留下的是两端不同的部分。

**这套做法适合脑电：要记录的量本来就是两点之差，干扰则以共同的形式出现在两端。同一个减法把前者留下，把后者消掉。**

配图：两路输入各自含同一份共模起伏与各自的脑电位，相减后共模消失。



### ③-2 减法只看电压，不看来源

那个减法依据的是两个输入端的电压关系。某一份电压来自脑、来自肌肉还是来自市电，放大器读不出来。

由此有两个后果，方向相反：

- 两片电极共有的脑活动，同样被减掉。参考位置越靠近信号源，共有的成分越多，记录到的幅度越小。
- 只出现在一端的干扰，同样被完整放大。眼动、某片电极下的肌肉活动、单片电极自身的电位漂移，都属于这一类。

所以「差分放大抑制干扰」这句话有前提：**要记录的成分在两端不同，干扰在两端相同。** 这个前提由电极的位置和接触状况决定，放大器本身管不了。

配图：两栏对照，左栏为共有的脑活动被减掉，右栏为单端干扰被完整放大。



### ④-1 两片电极的接触阻抗不相等，两端拿到的共模就不相等

卡 ③ 的前提是「干扰在两端相同」。这个前提在电极这一步失效。

干扰在体表是同一份共模电压 V_cm。它要到达放大器的两个输入端，得各自经过一片电极，每条通路都是一次分压：

```
输入端 1 = V_cm × Z_in/(R_e1 + Z_in)
输入端 2 = V_cm × Z_in/(R_e2 + Z_in)
```

两条通路的分压比由各自的接触阻抗决定。R_e1 与 R_e2 不相等，两个输入端拿到的共模就不相等。

**差出来的那部分满足「两端不同」这个条件，被当作信号放大。**

配图：同一份 V_cm 经两条带不同 R_e 的通路到达输入端，两端高度不齐。

### ④-2 差出来的那部分有多大

把两式相减、通分：

```
ΔV = V_cm × Z_in × (R_e2 − R_e1) / [(R_e1 + Z_in)(R_e2 + Z_in)]
```

Z_in 远大于两个 R_e，分母里两个括号各自约等于 Z_in，相乘得 Z_in²。分子上的那个 Z_in 与它约掉一个，分母里剩下一个 Z_in：

```
ΔV ≈ V_cm × (R_e2 − R_e1) / Z_in
```

两片电极接触阻抗之差 R_e2 − R_e1，称**阻抗失配**。两片贴得一样好，失配为零，ΔV 也为零。

V_cm 是两条通路的公因子。两边同除以它，得到的比例与 V_cm 多大无关：

```
ΔV / V_cm = 阻抗失配 / 输入阻抗
```

**同一份共模里漏成差模的比例，等于阻抗失配除以输入阻抗。**


### ④-3 V_cm 有多大

判据里还剩一个量没有取值：V_cm。

它指的是两片电极共有的那份电压。来源是市电——市电线路与人体之间存在寄生电容，人体与大地之间也存在电容，人体串在这条回路里，整体相对仪器零点被抬起一份电压。这份电压对头上每片电极相同，因此是共模。

它的大小由这条回路的分压决定。取人体对市电线路 2 pF、对地 200 pF 的指示值⁴，市电按 220 V 计，人体被抬起约 2.2 V（自算）。

地电极把人体经一片电极直接连到仪器零点，回路下臂换成这片电极的接触阻抗²，分压比随之改变。地电极用凝胶电极时 V_cm 约 **1.9 mV**，用干电极时约 **71 mV**（均为自算）。

后面按电极类型分别取这两个值。

配图：分压回路两态对照，未接地电极时人体抬起 2.2 V，接地电极后降到 50 mV。


### ④-4 干电极漏进来的电压比脑电本身还大

三个量都齐了。

**阻抗失配**取实测的离散程度。同一顶电极帽上 64 片干电极与 64 片凝胶电极、10 名健康志愿者头皮同步记录，凝胶电极 14 ± 8 kΩ，干电极 516 ± 429 kΩ²。标准差是**同类电极彼此之间**的差异——两片凝胶电极之间差几千欧姆，两片干电极之间差几百千欧姆。

**输入阻抗**取 14.5 MΩ³。

**V_cm** 见卡 ④-3。

```
         失配      漏进比例    漏进电压
凝胶     8 kΩ      5.5×10⁻⁴    1.07 µV
干电极   429 kΩ    3.0×10⁻²    2.11 mV
```

对照头皮 EEG 本身：β 活动 10–20 µV⁶，全带宽叠在一起的上界约 100 µV¹。**凝胶电极漏进来的约 1 µV 尚可接受，干电极的 2.11 mV 是 β 活动的上百倍。**

由此，Z_in 的两条理由合在一起：它越大，被扣掉的幅度越少，漏进来的共模也越少。把两片电极贴得一样好，与把输入阻抗做高，压的是同一个比值的两端。

配图：两类电极的失配与漏进电压对照，与 β 活动幅度同轴比较。


### ⑤ 两条要求都是同一个分母上的比值

回到开头那两条要求。各自的判据都是一个比值。

```
幅度损失的比例   = R_e / Z_in
共模漏进的比例   = 阻抗失配 / Z_in
```

分母是同一个：放大器的输入阻抗。分子都在电极那一侧，一个是接触阻抗本身，另一个是两片电极之间的差。

所以准确记录要两侧同时满足条件。**仪器一侧能做的，是把 Z_in 做大；操作一侧能做的，是把每片电极贴好，并且贴得一样好。** 任何一侧不到位，另一侧再好也压不住那个比值。

记录前做皮肤准备、涂导电膏、等阻抗读数降下来并趋于一致，压的就是这两个分子。

配图：两个比值并排，分母同为 Z_in，分子分别为 R_e 与阻抗失配。
