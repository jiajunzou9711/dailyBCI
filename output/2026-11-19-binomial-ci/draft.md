# 从观测数据描述事件概率（95% 置信区间）— 工作稿

备料：同目录 source_excerpt.md（ising_latest_explain 会话摘录）。例子一律用示意数字，不用 0331 实验室数据。

## 大图景（2026-11-24 对齐）

- **总问题**：一个事件做了 n 次试验、成功 k 次，它的概率是多少？
- **答案两部分**：点估计（point estimate）p̂ = k/n；区间估计（interval estimate）95% CI。
- **框架**：频率学派（frequentist）；贝叶斯可信区间（credible interval）结尾一句带过。

## 暂定骨架（讲完再定稿）

0. 引入：为什么要问这个问题（待讨论）
1. 要估的是看不到的真实概率 p，手里只有观测值 p̂
2. p̂ 随抽样波动，标准误（standard error）SE = √(p(1−p)/n)
3. 置信区间是反推：保留所有「观测值落在其 ±1.96 SE 之内」的候选 p
4. SE 里要用未知的 p：Wald 代入 p̂（n 小或 p̂ 近 0/1 失效）vs Wilson 解二次方程
5. 前提：trial 独立、成功概率不变

## 讲解记录

### 0. 引入（已落稿 2026-11-24）

范围：只谈行为学指标，不涉及神经元放电或解码（2026-11-24 用户定）。

例子只用通用行为指标，不用 win-stay / lose-switch（用户自己数据特有，不够通用）。

候选写法：行为实验里报告的很多量都是概率，由有限次 trial 算出，例如二选一任务的正确率、选择某一侧的比例。它们都是 k/n。同样是 0.8：
- 8/10 → 95% Wilson 区间约 [0.49, 0.94]
- 800/1000 → 约 [0.77, 0.82]

（以上区间为自算，Wilson 公式，z = 1.96。）只报一个比例、不报 n 和区间，读者无法判断这个 0.8 有多可靠。由此引出总问题。

### 1. 要估的 p，手里的 p̂（已落稿 2026-11-24）

- 模型：每次试验独立、成功概率同为 p（伯努利试验，Bernoulli trial）；p 不可直接观测。
- 观测：p̂ = k/n，例 83/100 = 0.83。
- 关键区分：p 是固定未知常数；p̂ 是随机变量，重做实验会变。
- k/n 是最大似然估计（MLE）。「无偏：p̂ 的分布以 p 为中心」移到第 2 节讲（2026-11-24 用户认为放卡 4 突兀）。

### 2. p̂ 的波动有多大（已落稿 2026-11-24）

- 重做很多遍，p̂ 形成抽样分布（sampling distribution）：中心是真实的 p（无偏），宽度是标准误 SE = √(p(1−p)/n)。
- 0.83 只是从这个分布里抽到的一个值，不是分布中心。
- SE 来历：单个 trial 结果只有 0 和 1，由数学推导易得其方差为 p(1−p)；n 个独立 trial 取平均，方差缩小为 1/n，开根号得 SE。（推导不展开，2026-11-24 用户定。）
- 例（p = 0.83，自算）：n = 10 → 0.119；n = 100 → 0.038；n = 1000 → 0.012。n 增大 100 倍，SE 缩小到 1/10。
- 卡点：SE 公式里要用真实的 p，而 p 正是未知的 → 第 3、4 节。

### 3. 置信区间是反推出来的（已落稿 2026-11-24）

- 换问法：p 取哪些值时，观测到 0.83 不算罕见？
- n 足够大时 p̂ 近似正态（中心极限定理），95% 落在 ±1.96 SE 内；对每个候选 p 用自己的 SE(p) 检验，保留 0.83 落在 p ± 1.96·SE(p) 内的 p。
- 例 83/100（自算）：0.70 排除、0.78 保留、0.90 排除；区间约 [0.745, 0.891]。全程不需要真实 p。

### 4. Wilson 与 Wald（已落稿 2026-11-25）

- Wilson：第 3 节的反推解 (p̂ − p)² = 1.96² × p(1−p)/n，二次方程两根即区间两端。
- Wald：把 p̂ 代入 SE，p̂ ± 1.96·√(p̂(1−p̂)/n)。
- 自算对比：83/100 Wald 0.756–0.904 / Wilson 0.745–0.891；8/10 Wald 0.552–1.048 / Wilson 0.49–0.943；10/10 Wald 1–1 / Wilson 0.722–1。
- 出处（已核 2026-11-25，Project Euclid 摘要页）：Brown, Cai & DasGupta 2001, Statist. Sci. 16(2):101–133, DOI 10.1214/ss/1009213286。摘要：Wald 覆盖率的混乱「far more persistent than is appreciated」；推荐小 n 用 Wilson 或等尾 Jeffreys，大 n 用 Agresti-Coull。

### 5. 前提（已落稿 2026-11-25）

- 两条前提：trial 相互独立；答对概率 p 不变。
- 任一不成立 → 实际波动大于 √(p(1−p)/n) → 区间偏窄。
- 常见情形：热身期（违反 p 不变）；重复上一次选择（违反独立）。
- 检查：滑动窗口看平稳；补救：区组自助法（block bootstrap）。

### 收尾方案（2026-11-25 定，未落稿）

- 结语复述路径：k/n 点估计 → p̂ 围绕 p 波动、宽度 SE → 区间=保留与观测值相容的 p → Wilson 算法 → 两条前提。
- 实操：报比例同时给 n 与 95% Wilson 区间，Methods 写明独立前提。
- 边界一句：频率学派；贝叶斯用 Beta 后验，得可信区间（credible interval），解释不同。
- 不加「误差单位（trial vs session/动物）」（用户定）。
- 参考文献：Brown et al. 2001（待核）。

## 卡片文案（2026-11-25 按「断言→理由→证据→转场」自查重写；卡 1 封面、卡 2 目录待定）

### 卡 3 · ①同样是 0.8，可靠程度可以差很多

只报一个比例，读者无法判断它有多可靠。

行为实验里的正确率、选择某一侧的比例，都是由有限次 trial 算出的 k/n。trial 越少，k/n 的随机误差越大。

如图，8/10 与 800/1000 的比例都是 0.8：前者的 95% 置信区间（confidence interval）约为 0.49–0.94，下界低于 0.5，连「高于随机水平」都不能确定；后者约为 0.77–0.82。（区间为作者自算，算法见后文。）

由此，本期的问题是：n 个 trial 里答对 k 个，我们能对答对的概率说什么？答案分两部分：一个点估计（point estimate），一个区间估计（interval estimate）。

### 卡 4 · ②真实概率 p 固定但未知，观测值 p̂ 每次都会变

真实概率 p 是固定的未知常数，观测值 p̂ = k/n 是随机变量。

- p：这只动物在这项任务里答对的概率，无法直接观测
- p̂：再做一遍同样数量的 trial，答对数会变，p̂ 也跟着变

这里假设每个 trial 相互独立、答对概率都是同一个 p，这类试验叫伯努利试验（Bernoulli trial）。

例：100 个 trial 答对 83 个，p̂ = 0.83。用 k/n 作点估计的依据是：在所有候选的 p 里，p = 0.83 让「恰好答对 83 个」的概率最大，所以它是最大似然估计（maximum likelihood estimate）。

下一张讲 p̂ 的波动有多大。

### 卡 5 · ③p̂ 围绕 p 波动，波动幅度由 n 决定

p̂ 的波动以真实的 p 为中心，幅度是标准误（standard error，SE）：

SE = √(p(1−p)/n)

把同样数量的 trial 重做很多遍，得到的 p̂ 构成一个抽样分布（sampling distribution），SE 就是这个分布的标准差。我们手里的 0.83，只是从中抽到的一个值。

公式的来历：单个 trial 的结果只有 0 和 1，由数学推导易得其方差为 p(1−p)；n 个独立 trial 取平均，方差缩小为 1/n，开根号即得 SE。

如图，p = 0.83 时，n 从 10 增大到 1000，SE 从约 0.119 缩小到约 0.012：n 增大 100 倍，SE 只缩小到 1/10。

SE 公式里需要真实的 p，而 p 正是未知的。下一张讲怎么处理。

### 卡 6 · ④95% 置信区间由所有与观测值相容的 p 组成

95% 置信区间由所有「与观测值相容」的候选 p 组成，求它不需要知道真实的 p。

相容的判据：n 足够大时，p̂ 的抽样分布近似正态分布（中心极限定理，central limit theorem），约 95% 的取值落在中心 ±1.96 SE 以内。对每个候选 p，用它自己的 SE(p) 检验：0.83 落在 p ± 1.96·SE(p) 以内就保留，落在外面就排除。

如图，以 83/100 为例：p = 0.70 和 0.90 被排除，0.78 被保留。所有保留下来的 p 合起来约为 0.745–0.891，这就是 95% 置信区间。

下一张讲这个区间的实际算法。

### 卡 7 · ⑤Wilson 区间是解析解，Wald 区间在 n 小或 p̂ 靠边时失效

Wilson 区间（Wilson score interval）是上一张反推过程的解析解；Wald 区间是一种近似，在 n 小或 p̂ 靠近 0、1 时失效。

- Wilson：SE 里用候选 p，解 (p̂ − p)² = 1.96² × p(1−p)/n，这个二次方程的两根即区间两端
- Wald：SE 里直接代入 p̂，区间为 p̂ ± 1.96·√(p̂(1−p̂)/n)

如图，Wald 区间在 8/10 时上端超过 1，在 10/10 时缩成一个点。原因是 Wald 把带误差的 p̂ 当作真实的 p 来算波动。Brown 等人系统比较过这几种区间的覆盖率（coverage probability，重复实验时区间包含真实 p 的比例），发现 Wald 区间的覆盖率不稳定，推荐 n 小时用 Wilson 等区间¹。

两种算法依赖同一组前提，下一张讲。

### 卡 8 · ⑥trial 不独立或概率变化时，区间会偏窄

trial 之间不独立，或答对概率在实验中变化，算出的区间都会偏窄，估计看上去比实际更确定。

原因是两种算法都用 SE = √(p(1−p)/n)，这个公式依赖两条前提：trial 之间相互独立；整场实验里 p 是同一个值。前提不成立时，p̂ 的实际波动大于公式给出的值。

行为实验里常见两种情形：

- 动物有热身期，开头一段正确率偏低：p 不恒定
- 动物倾向于重复上一次的选择：trial 不独立

检查方法是用滑动窗口画出正确率随 trial 的变化，看是否平稳。不平稳时，可以改用区组自助法（block bootstrap）估计区间：按连续的 trial 块有放回地重抽样，保留块内 trial 之间的依赖。

### 卡 9 · 结语

从「n 个 trial 里答对 k 个，答对的概率是多少」出发，我们依次讲了：

- k/n 是 p 的点估计
- p̂ 围绕 p 波动，幅度为 SE = √(p(1−p)/n)
- 95% 置信区间由所有与观测值相容的 p 组成，Wilson 区间是它的解析解
- 这套计算依赖 trial 独立、答对概率不变两条前提

实操上，报告比例时同时给出 n 和 95% Wilson 区间，并在方法部分写明独立性前提。

本期讲的是频率学派（frequentist）的做法。贝叶斯（Bayesian）方法用 Beta 后验分布描述 p，得到的是可信区间（credible interval），两种区间的解释不同。

参考文献
1. Brown, L. D., Cai, T. T., & DasGupta, A. (2001). Interval estimation for a binomial proportion. Statistical Science 16:101–133.
