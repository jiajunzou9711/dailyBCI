## 主线（用户 2026-09-04 确认）

1. 要测的东西天生是差 —— 生物电信号是细胞电流在组织这团导电介质里造成的电位分布
2. 第一个问题：另一端放哪 —— 参考电极，进减法，定义信号的零点

## 已定稿

### ① 信号从哪来

先从最底下那层说起。

细胞干的事其实很朴素，就是让离子跨过膜跑一跑。膜内侧少了点电荷，外侧就多了点，胞外那一片立刻有电流从膜的一处流出来、绕着细胞外液回到另一处。

关键在下一句。细胞外液不是理想导体，它有电阻。上一期那条 U = I·R 在这儿第二次生效，电流只要流过有电阻的东西，这东西内部就一定出现电位差。

所以你把电极插进组织，它读到的从来不是细胞本身，是细胞的电流在这团组织里摊开的那张电位分布图。这团组织在电生理里有个正式名字，叫体积导体（volume conductor）。

---

### ② 所以测量必然是两点

那这张电位分布图，能不能直接读出某一点是多少？

不能。上一期讲透过一次，电位分布里的每个数值都是省略句，它们要等你选定同一个零点之后才有数字。这张图真正给你的东西只有一个，任意两点之间差多少。这个差是物理的，你把零点挪到哪儿它都不变。

所以一次记录必须动用两个电极。这不是工程上的将就，是被测的那个量本来就只存在于两点之间。

也正因为这样，下一个问题的形式就被定死了。既然第二个电极非有不可，那它该放在哪。放的地方不一样，Vᵢ − V_ref 就是完全不同的物理量。这个第二电极，就是参考电极。

---

### ③ 那第二个电极放哪儿

上一张的结论是必须有两个电极。那第二个放哪儿。

第一反应通常是找个电位为零的地方，减出来就是纯的那一端了。

这个直觉是错的。

参考电极同样贴在这具身体上，同样泡在那团体积导体里，电流一流过去它就有电位，而且随时间变。身体上没有电位为零的地方。

所以真实的读数长这样。

```
通道 i = V_i(t) − V_ref(t)
```

V_ref 不是 0，也不是常数，是一条完整的时间序列。

### ④ 那我们到底减掉了什么

既然减不掉一个零，这一减减掉的是什么。

是另一条信号，而且它进了每一个通道。

于是两件事同时发生。通道之间被人为拉出相关，哪怕两个脑区各干各的，数据里也共享同一条 −V_ref(t)。参考点自己拾到的东西也会出现在你所有数据里，乳突带心电，耳垂带咀嚼肌电，鼻尖带眼动，它们在每个通道上同时出现，看着特别像一个广泛分布的脑活动。

### ⑤ 所以选参考，是在两条打架的要求之间折中

先算一件事，组织里的电位掉得有多快。

一个点往外注入电流 I，介质电导率 σ，电流朝各方向散开，穿过半径 r 的球面时电流密度是 I/(4πr²)。用 J = σE 换成场强，沿半径积一次，得到

```
V(r) = I / (4πσr)
```

r 翻一倍，电位掉一半。

有了这条，两条判据就出来了。

第一条，参考点不能带着你要找的信号。减法会把两边共有的部分抵消掉，离得越近共有的越多。参考放在 2 mm 处，1 mm 那一点的幅度只剩一半。

第二条，参考点不能带着别的源。它带什么，就往所有通道里灌什么。

麻烦在于这两条的方向是反的。一条让你往远处走，一条让你往干净的地方走，而头面部到处是心电肌电眼动，没有位置能同时满足。乳突耳垂鼻尖之争，争的从来不是谁更接近零，是这个折中怎么取。

### ⑥ 减完了还能不能换

能，不用重录。

```
(V_i − V_a) − (V_b − V_a) = V_i − V_b
```

拿已经录好的 b 通道去减，这叫重参考。

得跟上一期那条自由度分清楚。上一期是给所有电位加同一个常数，每个点每个时刻都一样，任意两点的差一个不变，波形完全不动。重参考减掉的是 V_b(t)，一条随时间起伏的信号，不是常数，所以每一道波形都真的变了。

但任意两个电极之间的差 V_i − V_j 还是没变。换参考改的是通道 i 长什么样，改不了 i 和 j 相差多少。

物理没变，呈现变了。所以某个成分在换参考之后消失，第一反应应该是它本来属于参考点，而不是它属于脑。

---

### ⑦ 还有第三片电极

到这儿两个电极已经够用了，Vᵢ 减 V_ref，讲完了。

可你去看任何一台真机，上面还有第三片金属，标着 GND 或者 DRL。它一个数据点都不贡献，波形里根本没有它。

那它凭什么在那儿。

答案不在人身上，在仪器上。前面我一直默认放大器能直接读出那个差，现在得检查这个默认成不成立。

它不成立。理想的减法器可以只看差，不管两端各自在哪，真实放大器做不到。放大器内部是晶体管，每个晶体管开不开，取决于它的输入端相对于芯片自己那个零点是多少伏。所以放大器干的事分三步。

```
a = V₊ − V_amp0
b = V₋ − V_amp0
输出 = G · (a − b) = G · (V₊ − V₋)
```

V_amp0 是仪器自己的零点，供电系统的负端，一块属于机器不属于身体的金属。

它在结果里消掉了。但 a 和 b 是芯片内部真实存在的电压，第三步能不能发生，全看前两步成不成立。

### ⑧ 差是对的，不代表差能被算出来

a 和 b 得落在芯片的电源轨之间才有意义，比如 0 到 3.3 V，实际还更窄一点。这个区间叫共模输入范围。

超出去不是读数偏一点，是那一级晶体管直接离开工作区，输出贴在轨上不动。

问题来了，人体的电位凭什么落在这个范围里。

凭不了，人体是浮的。墙里的电线带着 220 V 五十赫兹，它和人体之间有个寄生电容 C₁，人体和大地之间又有个 C₂，而市电的中性点是接大地的。这就是一条闭合回路。

```
火线 → C₁ → 人体 → C₂ → 大地 → 中性点
```

两个电容串起来就是分压器，容抗是 1/(ωC)，所以电容越小分到的电压越大。

```
V_body = V_m × C₁/(C₁+C₂)
```

取 C₁ 一皮法，C₂ 一百皮法，220 V 代进去，得到大约 2.2 V。人体整体带着 2.2 V 在那儿五十赫兹地摆，所有电极一起摆，摆得一样多。

对一个 3.3 V 供电的放大器，2.2 V 已经足够把 a 和 b 顶到边上去。

差还是那个差，一点没错。可它算不出来了。

### ⑨ 那根线做的事

地电极把身体经一根导线接到 V_amp0，分压器的下臂就被换掉了。

原来下臂是 C₂ 的容抗。

```
Z_C₂ = 1/(2π × 50 × 100 pF) = 31.8 MΩ
```

现在下臂是这片电极的接触阻抗 R_e，取 10 kΩ，跟 31.8 MΩ 并联，结果还是 10 kΩ。

上臂那边容抗 3.18 GΩ，比下臂大五个数量级，所以回路电流几乎只由它决定。

```
I = 220 V / 3.18 GΩ ≈ 69 nA
V_cm = 69 nA × 10 kΩ ≈ 0.69 mV
```

2.2 V 变成 0.69 mV，降了三千多倍。这个倍数正好是 31.8 MΩ 除以 10 kΩ。下臂阻抗降多少倍，共模电压就降多少倍。

磨皮、涂导电膏、按住电极多等一会儿，全是在降 R_e，全是同一件事。

地电极不进减法，它保证减法能发生。

### ⑩ 那根线的另一头，具体接在哪

心电是右腿电极，贴右小腿或者右髋，离心脏电轴最远，肌肉也少。驱动右腿这个名字就是这么来的。

体表肌电贴骨性突起，腕骨、鹰嘴、髌骨，选骨头是因为上面肌肉薄，电学上安静。

头皮脑电多数贴前额或者乳突。BioSemi 是个例外，它用 CMS 和 DRL 两片电极，官方指南写得很明确，CMS 尽量放在电极阵列中间，因为它才是真正当共模参考的那个，DRL 放哪儿不重要，在身上就行，图方便一般放在 CMS 三英寸以内。这两片构成一个反馈环，把被试的共模电压往 AD 盒的参考电压上拽。

皮层表面和皮层内就不贴皮肤了，走颅骨螺钉。犹他阵列的地线在术中缠在螺钉上，绕三圈以上、压住自己，螺钉要接触到硬脑膜，参考线同法接另一颗螺钉，或者跟地线一起放进硬膜下腔。

五个地方，一条共同的道理。地电极永远选在既导电、又尽量不产生你要记录的那种信号的位置。骨头、右腿、颅骨螺钉，理由都是这一条。

### ⑪ 可这根线，恰恰是危险本身

前面说仪器零点接大地。那再看一眼这条路。

```
火线 → 人体 → 地电极 → 仪器保护地 → 大地 → 中性点
```

电流要伤人，得先有回路。身上贴着一片通往大地的低阻抗电极，回路就现成了。万一身体另一处碰到带电体，或者设备自己绝缘故障，电流就从这条路走。

皮肤本来是主要的阻抗屏障，可植入电极绕过了它。IEC 60601-1 对直接用于心脏的 CF 型器件，患者漏电流限值是正常状态 10 µA、单一故障 50 µA。这是标准给的限值，不是生理阈值，但它给出的量级说明了这条路有多敏感。

所以医疗设备的选择是不给这条路。

电池供电，仪器零点不接大地，它自己也浮着。回路只能靠仪器对地的寄生电容 C₃ 闭合，五十赫兹下几十兆欧，电流被压到微安以下。

而放大器只看身体相对 V_amp0 的差。R_e 把两者绑在一起，它们作为一个整体相对大地摆，这个摆动放大器完全看不见。

低阻抗接地既是共模噪声的解药，也是漏电流的通道。断了它，噪声问题得换别的手段解决，隔离电源、DRL 主动驱动，都是为了补这一刀。

安全和噪声，在这里是同一件事的两面。

---

### ⑫ 被动接地这条路，走到头了

⑩ 和 ⑪ 那两张聊的是安全，属于岔出去的一段。现在回到 ⑨ 那个式子上。

```
V_cm = I × R_e
```

想把共模再往下压，可调的量只有 R_e，那片地电极的接触阻抗。

可 R_e 有物理下限。挡在中间的是皮肤角质层，磨皮、涂导电膏能弄到几 kΩ，再往下就得破皮了。干电极更难看，MΩ 量级。耳道里、头发丛里这些根本没法磨皮的地方，只会更高。

那 0.69 mV 是在 R_e 等于 10 kΩ 的乐观假设下算的。换成干电极 1 MΩ，同样 69 nA 的电流，共模直接变成 69 mV。

所以得换个思路。

不再指望把 R_e 做小，改成主动把共模顶回去。

这就是 DRL。

### ⑬ DRL 的思路，就是负反馈

Driven Right Leg，驱动右腿。Right Leg 来自心电的标准导联，右腿历史上就是那片接地电极，离心脏电轴最远、肌肉最安静。Winter 和 Webster 在 1983 年把它从被动接地改成主动驱动，名字沿用至今。所以现在脑电、肌电上那片电极也叫 DRL，虽然它根本不在腿上。

关键词是前面那个 Driven。这片电极不再是被动接一根线到 GND，它的电位由一个运放的输出主动决定。

这个环路分三步走。

第一步，测。把各个测量电极的电位用电阻网络求平均。差模在电极之间有正有负，平均之后基本抵消，共模在每个电极上都一样，平均之后原样保留。所以这个平均值就是共模的估计。BioSemi 用一片专门的 CMS 电极做同一件事。

第二步，放大并反相。

第三步，灌回去，经第三片电极送回身体。

于是身体不再是被动地被市电电流推着走。它成了一个闭环里的节点，往上飘就被拉下来，往下掉就被推上去。原来那 69 nA 仍然灌进来，但它现在流进的是一个主动稳压的节点，不是一个被动的电阻。

这里有两处限制。一是输出端必须有限流措施，把最坏情况下能注入人体的电流卡住，这是患者安全的硬要求。二是环路增益不能一味往大做，Winter 和 Webster 那篇的主要结论就是高环路增益会让电路不稳定，他们给出的正是一组在不失稳的前提下把共模压到最小的设计方程。

### ⑭ 共模压小了，可它没消失

按 ⑦ 那个式子，共模应该在减法里被完全消掉，剩多少都无所谓。

那还费劲压它干嘛。

因为那行式子是理想的。它假设两端处理得完全对称，真实器件做不到，总有一点共模漏进输出，而漏进去的部分看起来就是信号。

```
输出 = G_dm · V_dm + G_cm · V_cm
CMRR = G_dm / G_cm
```

CMRR 就是度量这个漏得有多少的指标。它不是一个模块，也没有做任何处理，抑制共模那个动作是差分结构本身完成的，CMRR 只是在说这一步做得干不干净。

芯片内部为了让它好看，做的是匹配，决定增益的那几个电阻必须严格等值，输入级的晶体管对必须对称。仪表放大器出厂时激光修调这些电阻，这就是它比三个运放搭出来的电路强的地方。

好的仪表放大器在 100 到 120 dB。取 100 dB 也就是十万倍，共模 0.69 mV 折算到输入端只剩

```
0.69 mV / 10⁵ = 6.9 nV
```

比几十 µV 的脑电小四个数量级。

所以有个结论挺反直觉的，芯片本身的 CMRR 几乎从来不是瓶颈。

### ⑮ 瓶颈在电极那一侧

共模要到达放大器输入端，得先穿过电极。每片电极有自己的接触阻抗，放大器输入端有输入阻抗 Z_in，这就是一个分压器。

```
+ 端拿到 V_cm × Z_in/(Z_in + Z₁)
− 端拿到 V_cm × Z_in/(Z_in + Z₂)
```

Z₁ 等于 Z₂ 的话，两端拿到的一模一样，仍然是纯共模，减掉就没了。

一旦不等，两端拿到的就不一样，差出来那点东西就是差模。放大器再也没法把它跟真信号分开，因为它现在就是差模。

```
误差 ≈ V_cm × (Z₁ − Z₂)/Z_in
```

代数看看差多少。V_cm 取 0.69 mV。

湿电极失配 5 kΩ，Z_in 一个 GΩ，误差 3.5 nV，可以忘掉。

干电极失配 500 kΩ，Z_in 一百 MΩ，误差 3.45 µV。和脑电信号同量级了。

所以可以改的有三处，把 Z_in 做大，让 Z₁ 和 Z₂ 接近，把 V_cm 压小。

Z_in 那一项，主流做法是把前置放大器直接做在电极上，信号一出电极就进高阻缓冲级，后面导线传的已经是低阻抗信号。失配那一项，湿电极靠规范的皮肤准备和同批电极，干电极做不到，只能改成在线监测阻抗，随时知道它漂到哪儿了。V_cm 那一项，就是刚讲完的 DRL。

规格书上印着 120 dB，你实际拿到多少，取决于你贴电极的手艺和电极自己稳不稳。

讲了这么多硬件，最后落回皮肤准备。
