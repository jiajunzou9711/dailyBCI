# 参考电极与地电极｜重写草稿

## 已定稿

### 本期范围与主线

核心问题：生物电记录中，参考电极和地电极分别起什么作用，为什么需要区分它们？

讲解顺序：测量两处的电压差 → 参考位置怎样影响结果 → 放大器需要什么工作条件 → 地电极怎样帮助建立这些条件。

全篇固定在头皮电极连接差分放大器的记录场景。采用平实的科学语言，表达清晰、流畅、简练；每段只推进一个必要信息。

### ① 记录测的是两处的电压差

头皮上的电极通过导线连接到差分放大器。差分放大器的作用，是放大两个输入端之间的电压差。

神经元活动产生跨膜电流，电流在具有电阻的头部组织中流动，形成随时间变化的电位分布。头皮电极记录的信号就来自这一分布。

描述某一点的电位，需要先选定参考零点。两点之间的电压差则与零点的选择无关，这也是仪器实际测量的量。

因此，一个记录通道需要两个电极：测量电极和参考电极。通道记录的电压，等于测量位置的电位减去参考位置的电位。

参考电极放在哪里，便会影响记录结果。

### ② 参考位置会影响记录结果

参考电极（reference electrode）常被理解为一个电位为零的位置。头皮上没有这样的位置。

因此，一个通道记录的是：

```
通道 i = V_i(t) − V_ref(t)
```

V_ref(t) 是一条完整的信号，它被同时减进每一个通道。换一个参考位置，减去的信号变了，每一道波形也跟着变。

参考位置由此受两条要求约束，而这两条方向相反。

**第一，参考不能带着我们要记录的信号。** 减法会抵消两个电极共有的成分。参考离信号源越近，共有的部分越多，记录到的幅度越小。两片电极紧挨着时，读数几乎只剩噪声。这条要求参考远离源。

**第二，参考不能带着别的电活动。** 参考位置附近的肌电、心电或眼动会进入每一个通道，表现为所有通道共有的波动，容易被误读为一次广泛的脑活动。这条要求参考选在电学上安静的位置。

头面部各处都有肌肉、眼睛和心脏的电场，没有一个位置能同时满足两条。因此，参考位置的选择是多重限制条件下的妥协。

### ③ 放大器怎么完成一次测量

两片电极选定了，是不是就能测到？还不行。

差分放大器（differential amplifier）无法直接感知两端之差。它内部的晶体管能否工作，取决于输入端相对**芯片自己的零点**是多少伏。因此它实际分三步完成测量。

先分别感知两个输入端相对自身零点的电压：

```
a = V₊ − V_amp0
b = V₋ − V_amp0
```

再把两者相减，V_amp0 在这一步消去：

```
a − b = (V₊ − V_amp0) − (V₋ − V_amp0) = V₊ − V₋
```

最后按增益 G 放大：

```
输出 = G · (a − b) = G · (V₊ − V₋)
```

V_amp0 是仪器的零点，属于机器，不属于人体。它在结果里消掉了，但 a 和 b 是芯片内部真实存在的电压。第三步能否发生，取决于前两步能否成立。

a 和 b 必须落在放大器的输入电压范围内。超出这个范围，那一级晶体管离开工作区，输出贴在电源轨上，前两步就没有结果。

### ④ 人体处在浮空状态

人体的电位凭什么落在这个范围里？没有任何东西保证这一点。

市电线路与人体之间存在寄生电容 C₁，人体与大地之间存在电容 C₂，而市电的中性点接地。三者构成一条闭合回路，两个电容串联成分压器。

```
火线 → C₁ → 人体 → C₂ → 大地 → 中性点
V_body = V_m × C₁/(C₁+C₂)
```

电容越小分到的电压越大。取文献给出的指示值 C₁ = 2 pF、C₂ = 200 pF¹，市电按 220 V 计，得 **V_body ≈ 2.2 V**（这是我按上述参数算的，原文未直接给出）。

由此，头上所有电极的电位一起被抬起约 2 V，抬升幅度相同。两点之差仍然准确，而 a 和 b 双双跑到放大器能处理的范围之外。

**电压差是对的，仪器算不出来。**

### ⑤ 地电极把人体拽回可测范围

问题现在很具体：人体整体相对仪器零点被抬起约 2 V，怎么把它拉回来。

办法是再贴一片电极，用一根导线把人体直接连到 V_amp0。这片电极就是地电极。

它改变的是上一张那个分压器的下臂。原来人体到大地只有 C₂ 这一条通路，200 pF 在 50 Hz 下的容抗约 16 MΩ（自算）。接上地电极后，人体到仪器零点多了一条实通路，阻抗是这片电极的接触阻抗 R_e。湿 Ag/AgCl 电极在前臂静息、未做皮肤准备的条件下实测为 350 kΩ ∥ 25 nF²。

下臂阻抗从十几兆欧降到几百千欧，相差约 45 倍（自算）。共模电压按同样比例下降，a 和 b 因此落回放大器能处理的范围内。

这条通路的阻抗越低，共模压得越狠。记录前做头皮准备、涂导电膏、等阻抗读数降下来，这些操作都在降低 R_e。

**这片电极不进入任何一个通道的减法。** 它一个数据点都不贡献，波形里没有它。它做的是让前面那个减法能够发生。

### ⑥ 这个「地」并不通向大地

上一张说地电极把人体连到 V_amp0。那 V_amp0 又连到哪里？墙上插座的地线吗？

在生物电记录设备里，通常不连。原因是安全。

电流要流过人体，需要一条完整的回路。人体一旦有一条低阻抗通往大地的路径，这条回路就已经具备了一半。设备内部绝缘失效，或人体另一处接触到带电物体，电流就会经人体和地电极流向大地。**流过人体的电流会造成伤害，这是设计上首先要排除的情况。** 地电极为共模建立的那条通路，同时也是这样一条回路的起点。

处理办法是把患者侧与市电侧在电学上切开：整机用电池供电，或用光耦、变压器把前端与市电部分隔离。V_amp0 因此是一个浮空的零点，它自己也不接大地。这样即使发生上述故障，回路里也没有低阻抗的返回路径³。

人体与仪器零点被 R_e 绑在一起，两者作为一个整体相对大地浮动。放大器只看人体相对 V_amp0 的差，这个整体浮动不进入读数。

所以「地电极」这个名称里的「地」，指的是仪器自己的零点。

回到全篇的问题：**参考电极进入减法，它定义信号的零点；地电极不进入减法，它让减法能够发生。**
