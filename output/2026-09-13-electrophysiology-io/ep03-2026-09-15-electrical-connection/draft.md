# 电气兼容决定连接方式（工作标题）

更新日期：2026-09-15。大纲已确认，正文逐块讨论中。

## 已定稿

### 一、两台设备怎样建立电气连接

一路信号从设备 A 的输出送到设备 B 的输入，落到电路上是什么？

1. **电压是两点之间的差，所以接收端要比较信号线与参考线。** 接收端测电压时会取走少量电流，这些电流经参考线流回发送端，所以参考线同时是回路。
2. **因此，一条连接至少要有两根导体：信号线与参考线。**

由此留下的问题是：回路两端，发送端能提供什么，接收端需要什么。

### 二、接上以后，两端怎样相互影响

#### 1. 输出端能提供什么

输出端提供两样东西：

1. **电压。** 数字输出给出高、低两个电平；模拟输出在一个范围内连续变化。
2. **有限的电流。** 输出端能提供的电流有上限。电流越接近上限，实际输出电压偏离设定值越多，因为输出端内部存在电阻，即输出阻抗（output impedance），电流流过时产生压降。

因此，说明书里「输出端能提供什么」要看三个量：**输出电压（电平或范围）、最大输出电流、输出阻抗**。

#### 2. 输入端需要什么

输入端的要求分两类：

1. **能接受的电压范围。** 其一是能正确读出：数字输入规定了判定阈值，高于某电压判为「高」，低于某电压判为「低」，两者之间为不确定区；模拟输入规定了测量范围，超出即削顶。其二是不被损坏：说明书另列绝对最大值（absolute maximum rating），超过它器件可能损坏，这个值通常比正确读出的范围更宽。
2. **需要取走的电流。** 输入阻抗（input impedance）越高，接收端取走的电流越少，整条回路里的电流就越小。这些电流全部由发送端提供，而发送端的电流有上限，内部的输出阻抗还会让电流产生压降。所以回路电流越小，发送端越不容易接近上限，输出电压也越接近设定值。

因此，说明书里「输入端需要什么」要看三个量：**判定阈值或输入范围、绝对最大值、输入阻抗**。

#### 3. 接上以后，信号有没有被改变

发送端的输出阻抗与接收端的输入阻抗，串联在同一个回路里。设定电压分到这两个阻抗上，接收端实际收到的，是分在输入阻抗上的那一部分：

```
接收端电压 = 设定电压 × 输入阻抗 / (输出阻抗 + 输入阻抗)
```

因此，信号是否被改变，取决于两个阻抗的比例：

- **输入阻抗远大于输出阻抗**：输入阻抗分到接近全部电压，接收端收到的就是设定值。
- **两者接近**：设定电压被分走一大块，信号明显变小。

以两组示意数值为例（数值为自设，不对应具体设备）：输出阻抗 50 Ω、输入阻抗 10 kΩ 时，接收端收到设定值的 99.5%；输入阻抗降到 50 Ω 时，只收到 50%。

这里讨论的是稳定电压。电平跳变时，线缆电容还会让边沿变慢，这属于时序问题，留到后续各期。

#### 4. 两端兼容的判断

由此，两端能否直连，核对三件事：

- **电压范围**：接上后的高、低电平落在接收端判定阈值内，最高电压低于绝对最大值。
- **驱动能力**：接收端所需电流远小于发送端最大输出电流。
- **阻抗**：输入阻抗远大于输出阻抗。

### 三、多台设备连在一起会增加什么问题

#### 1. 连接线两端接在哪里

**每台设备内部都有一根公共导体，称为电路地。** 设备里的所有电路都接到它上面。电压是两点之差，设备内部说「这里是 5 V」，指的是比电路地高 5 V。电路地就是这台设备自己的零点。

**数字输出口有两个接点。** 输出引脚给出高电平或低电平，高低都相对自己的电路地而言；地引脚直接连到设备内部的电路地。数字输入口同样有输入引脚与连到自身电路地的地引脚。

因此，一根连接线里的两根导体接的东西不同：

- **信号线**：A 的输出引脚 → B 的输入引脚。
- **参考线**：A 的地引脚 → B 的地引脚，即把 A 的电路地与 B 的电路地直接连在一起。

「高」与「低」是信号线上电压的两种状态。B 判断高低时，比较的是输入引脚与自身地引脚之间的电压差。

#### 2. 接线之前，两台设备可能已经连通

墙上的三孔插座有三根线：火线与零线之间有电压，负责供电；**保护地线**连到建筑物的接地系统，不参与正常供电。它为安全而设：设备的金属外壳接到保护地线，内部故障使外壳带电时，电流经保护地线流走并使断路器跳闸，人接触外壳时不致触电。

许多台式设备的电路地也连在保护地线上。两台设备都插在接地插座上、且各自的电路地接到保护地线时，即使两者之间一根线都没接，它们的电路地已经连通：

```
A 的电路地 → A 的电源线地线 → 墙里的地线 → B 的电源线地线 → B 的电路地
```

电池供电、两脚插头或电源带隔离的设备，电路地不接保护地，具体需查说明书或用万用表测量。

#### 3. 地环路怎样形成

接上连接线后，参考线又把两台设备的电路地直接连通。此时 A、B 的电路地之间有两条通路：参考线，以及电源线地线加墙里的地线。两条通路首尾相接，构成一个闭合的环：

```
A 的电路地 → 参考线 → B 的电路地 → B 的电源地线 → 墙里的地线 → A 的电源地线 → A 的电路地
```

这个环称为地环路（ground loop）。线都接得没有问题，环本身也不是故障；它的影响在于电流可以沿环流动，而环中包含参考线。B 读信号时比较的正是信号线与参考线之间的电压差，参考线上的额外电流会影响这个比较。

#### 4. 环里的电流从哪里来

**来源一：两个接地点之间的电位差。** 墙里的地线电阻很小，但不为零；同一栋楼里许多设备都接在这套地线上，它们漏到外壳的少量电流经地线流走。电流流过有电阻的导线，两端就出现电压差，因此 A、B 两个插座的接地点电位并不完全相同。

参考线两端经由两台设备的电路地和电源线，分别接到这两个接地点上。在电路上，它就是在两点之间与墙里地线并联的第二根导线：

```
          墙里的地线（原有电流在这里流）
A 插座接地点 ─────────────────── B 插座接地点
     │                                │
     └──── A 的地 ── 参考线 ── B 的地 ──┘
```

原本只能走墙里地线的电流，现在有一部分改走参考线，哪条通路电阻小，分到的电流就多。

**来源二：磁场感应。** 导线里有电流，周围就有磁场。实验室的电源线流着交流电（中国电网为 50 Hz），周围磁场也随之变化。变化的磁场穿过闭合的环，会在环里产生电压，环包围的面积越大、磁场变化越强，电压越大。地环路由两根电源线、连接线和墙里的地线围成，面积常常不小，于是环里感应出 50 Hz 的电流，其中一段经过参考线。这一来源不需要两个接地点之间原本存在电位差。

#### 5. 环里的电流怎样改变 B 读到的电压

参考线也有电阻。环里的电流流过参考线时，两端出现电压差，等于电流乘以参考线电阻。参考线一端接 A 的电路地，另一端接 B 的电路地，这个电压差就是两台设备电路地之间的电位差：A 的地与 B 的地不再等电位。

信号线上几乎没有这份电流。B 的输入阻抗很高，环路电流基本不走信号线，信号线上的电压仍是 A 相对自己的地给出的值。B 比较的却是输入引脚与自己的地之间的电压：

```
B 读到的电压 = A 输出的电压（相对 A 的地） ± 两个地之间的电位差
```

B 的地可能比 A 的地高，也可能比 A 的地低，因此公式中为正负号。来源二感应出的是 50 Hz 电流，两个地之间的电位差会在正负之间来回变化，叠加到信号上的主要是 50 Hz 的波动。

两类信号受到的影响不同：

- **数字信号**：叠加的电压小于阈值留出的余量时，高低仍能读对；超过余量，就会读错或误触发。
- **模拟信号**：叠加的电压直接混入测量值，没有余量可以吸收。

#### 6. 隔离怎样消除地环路

地环路要成立，需要一个闭合的导体环：参考线与电源地的通路首尾相接，缺任何一段都无法闭合。

隔离就是断开 A 与 B 之间的导体连接。在两台设备之间加入隔离器件，信号换一种形式穿过：

- **光**：A 侧的发光二极管按信号亮灭，B 侧的光敏器件接收光并转换回电平，这类器件称为光耦（optocoupler）。
- **磁**：A 侧电流产生变化的磁场，B 侧线圈感应出信号，如变压器或数字隔离器。

两侧之间只有光或磁场穿过，没有导线相连。参考线在隔离器件处断开：A 侧电路以 A 的地为参考，B 侧电路以 B 的地为参考，两个地之间不再有导体。地环路缺了一段，无法闭合，环路电流无法流过。隔离器件在 B 侧给出的电平本就相对 B 的地产生，两个地之间的电位差不再叠加到 B 的读数上。

前提是隔离器件 B 侧的电路由 B 侧供电。若它从 A 取电，电源线会重新把两个地连起来，隔离随之失效。

#### 7. 隔离的边界

隔离断开了导体环路，但有四件事需要另外核对：

1. **供电须一并隔离。** B 侧电路由 B 侧供电；若只有 A 侧有电源，需用带隔离的电源模块（隔离 DC-DC）给 B 侧供电，否则电源线会把两个地重新连起来。
2. **耐压有上限。** 两个地之间的电压超过器件的额定隔离电压，隔离层可能被击穿，数值查说明书。
3. **快速变化的干扰仍可能漏过。** 隔离层两侧没有导线，但存在很小的电容。电容阻挡稳定电压，却允许快速变化的电压通过，因此两个地之间剧烈而快速的电位跳变仍可能影响 B 侧。说明书以共模瞬态抗扰度（common-mode transient immunity，CMTI）标注器件能承受的变化速度。
4. **信号穿过需要时间。** 从 A 侧输入到 B 侧输出存在传播延迟（propagation delay）。闭环给光这类有时间要求的连接，须把它计入从检测到施加刺激的总延迟，具体数值查说明书。

涉及人体的连接另有医用隔离标准，要求更严，本期不展开。

常见的同轴线（如 BNC 线）外层既是参考线，也是屏蔽层。它阻挡的是外部电场的干扰，不能消除地环路。

### 四、怎样证明这条连接成立

分两步。

**1. 接线之前，查两端说明书。**

- **电压**：发送端的高、低电平落在接收端判定阈值内，并低于绝对最大值。
- **电流与阻抗**：接收端输入阻抗远大于发送端输出阻抗，所需电流远小于发送端最大输出电流。
- **地**：两台设备的电路地是否都接保护地。都接则会形成地环路，需考虑隔离。

**2. 接好之后，在接收端实测。**

用示波器测接收端输入引脚相对自身地的电压，看两件事：高、低电平是否落在阈值内；电平上有没有叠加 50 Hz 的波动。

查说明书只能说明两端应当兼容，实测才能确认信号实际正确到达。

### 结语

一路信号从一台设备送到另一台设备，落到电路上至少要有信号线与参考线两根导体。两端能否直连，看电压范围、驱动能力与阻抗。两台设备都经保护地接地时，参考线会与电源地构成地环路，环里的电流改变接收端读到的电压，隔离可以断开这个环路。最后，接线前查说明书，接好后在接收端实测。

两端怎样正确连接清楚之后，接下来的问题是：每类接口内部怎样产生、转换和解释信号。这些留到后续各期。

### 核心问题

知道 A 的输出要送到 B 的输入，还不足以确定两者能否直接连接。本期回答：**怎样连接，才能让接收端正确接收到发送端的信号，同时满足两端的电气条件？**
