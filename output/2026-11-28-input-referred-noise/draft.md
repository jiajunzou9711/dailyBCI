# 讲解笔记

讲解深度（2026-11-28 用户定）：不讲到元件物理（热噪声 / 1/f / 散粒噪声的机制太细，不进笔记与成稿）；严格按骨架顺序、按读者逻辑讲。

## 开篇：规格表上这个数是什么（2026-11-28 讲）
- 原文：Intan RHD2000 datasheet p.7 的参数表一行「Amplifier Input-Referred Noise｜2.4 µVrms｜Typical. Varies slightly (< 15%) with amplifier bandwidth.」
- 一句话答案：放大器自己产生的噪声，折算到输入端后的均方根值。
- 读这一行要懂的三个词：
  - 输入参考（input-referred）：折算到输入端，单位与电极上的信号相同，可以直接比（①展开）。
  - µVrms：均方根（root mean square, rms），描述随机波动的典型幅度。噪声没有固定峰值，所以用 rms。
  - Typical：典型值，不同芯片之间有差异，不是保证值。
- 它不等于记录噪声：记录到的噪声 = 放大器噪声 + 电极热噪声 + 环境干扰 + ……，这一行只给出第一项，所以是下限。

## ① 是什么

### 1.2 为什么要等效到输入端（2026-11-28 已讲）
- 定义：放大器输出端的噪声除以增益，等效到输入端。
- 理由：输出端噪声随增益设置变化，不能直接比较。以 Intan RHD2000 为例，增益 192、输入参考噪声 2.4 µVrms，输出端噪声约 2.4 × 192 ≈ 461 µVrms（自算）；增益改变，输出噪声随之改变，放大器本身并没有变好或变差。除以增益后，结果与增益无关，单位与神经信号同为 µV，可以直接回答「多小的信号会被这个放大器淹没」。
- 模型：一个无噪声的理想放大器，输入端串一个噪声源，使输出与真实放大器相同；这个噪声源的大小就是输入参考噪声。

# 卡片文案（落稿）

## 开篇卡（2026-11-28 落稿）

**规格表上的噪声值，只是放大器自己的噪声**

放大器芯片的规格表里，通常有一行「输入参考噪声（input-referred noise）」。它是放大器自己产生的噪声，折算到输入端后的大小。

以芯片厂商 Intan 的 RHD2000 系列为例，这一行写着 **2.4 µVrms**，后面注明「典型值」¹。读懂它要懂三个词：
- **输入参考**：折算到输入端，单位与电极上的信号相同，可以直接比较。
- **µVrms**：均方根值（root mean square，rms），表示随机波动的典型幅度。噪声没有固定峰值，所以用 rms。
- **典型值（typical）**：芯片之间有差异，这个数不是保证值。

这一行不等于我们记录到的噪声。记录到的噪声还包括电极热噪声和环境干扰，这一行只给出放大器这一项，所以它是记录噪声的**下限**。

## ① 卡（2026-11-28 落稿）

**输入参考噪声，是把放大器噪声折算回输入端的值**

放大器自身也产生噪声，这些噪声和信号一起被放大，所以输出端的噪声大小取决于增益。「输入参考（input-referred）」指的是把输出端的噪声除以增益，换算回输入端；这里的「参考」是「折算到」的意思，与参考电极无关。换算后，它和电极上记到的神经信号单位相同、量级可比，可以直接比较。

## ①′ 卡（2026-11-28 落稿）

**规格表上的输入参考噪声，主要来自放大器**

以 Intan RHD2000 为例，一颗芯片上集成了三种功能：
- **放大**：把 µV 级的神经信号放大 192 倍¹；
- **滤波**：限定记录的频段；
- **模数转换**：16 位 ADC 把电压变成数字。

三者都会产生噪声，其中放大器最大。ADC 的量化噪声（quantization noise）折算到输入端约 **0.056 µVrms**（按规格书给的最小分辨电压 0.195 µV 除以 √12 算出），比放大器的 2.4 µVrms 小约 40 倍。

原因在于放大器位于链路最前端。后面各级的噪声折算回输入端时，都要除以前面的增益²；只有第一级放大器的噪声不被缩小。所以第一级增益足够大时，输入参考噪声基本由它决定。

## ② 卡（2026-11-28 落稿）

**这个数是在输入为 0 时测出来的**

测输入参考噪声，要先让放大器的输入为 0，不接任何信号。这时输出端只剩放大器自己的噪声。记录这段输出，除以增益，算出的 rms 就是规格表上的数。

Harrison 与 Charles 2003 年报告的一款神经记录放大器就是这样核对的：记录输出噪声波形、除以增益，得到 **2.2 µVrms**，与噪声谱积分的结果一致³。他们给出的积分频段是 0.5 Hz 到 50 kHz。

这个 rms 只在测量用的频段内成立，换一个频段数值就会变。下一张讲为什么。

## ②′-1 卡（2026-11-28 落稿，扩写为三张）

**噪声的大小，由它在各频率上的分布累加而来**

噪声可以拆成许多不同频率的成分。**功率谱密度（power spectral density，PSD）**记作 S(f)，表示频率 f 处每 1 Hz 宽度里的噪声功率，单位 V²/Hz。

测量从 f1 到 f2 这个频段时，把其中每个频率的 S(f) 累加起来，就是噪声 rms 的平方：

```
Vrms² = f1 到 f2 内所有 S(f) 之和（即 S(f) 对 f 积分）
```

如果 S(f) 在这个频段里处处相同，累加就变成乘法：

```
Vrms² = S × (f2 − f1)
```

所以一个频段的噪声由两件事决定：频段多宽，以及其中的 S(f) 有多高。低频段即使窄，只要 S(f) 高，总噪声也可以更大。

## ②′-2 卡（2026-11-28 落稿）

**放大器的噪声谱分两段：高频平，低频翘**

- **白噪声（white noise）**：高频段的 S(f) 是常数，每 1 Hz 的功率相同。
- **1/f 噪声（又称闪烁噪声，flicker noise）**：低频段的 S(f) 与频率成反比，频率降到 1/10，S(f) 升高 10 倍。

两段的分界点叫**拐角频率（corner frequency，fc）**。两段合起来写作：

```
S(f) = e² × (1 + fc / f)
```

e² 是白噪声段的谱密度。f 远大于 fc 时，括号约等于 1，谱是平的；f 远小于 fc 时，fc / f 一项占主导，谱随频率降低而升高。

Harrison 与 Charles 2003 年报告的一款神经记录放大器，白噪声段为 21 nV/√Hz（即 e），fc = **100 Hz**³。fc 取决于芯片设计，这只是一个例子。

## ②′-3 卡（2026-11-28 落稿）

**fc 以下，噪声由频段两端的比值决定**

1/f 段的 S(f) = K / f，K 是一个常数。把它从 f1 累加到 f2：

```
Vrms² = K × ln(f2 / f1)
```

ln 是自然对数。结果只取决于两端的比值，所以**每个十倍频程贡献相同的功率**：1–10 Hz 与 10–100 Hz 一样多。

固定上限 f2、把下限 f1 往下移时，每移动 1 Hz 增加的功率是 K / f1。f1 越接近 0，增加得越快：下限在 0.2 Hz 处时，每降低一点增加的功率是在 1 Hz 处的 5 倍。

实际记录中，下限有两道限制：
- **高通滤波**：本来用来去掉电极–组织界面的直流偏置（DC offset）³，同时也截住了频段下限；
- **记录时长 T**：能分辨的最低频率约为 1/T。

所以 1/f 噪声不会无限增大。下一张按要记录的信号，看这个噪声够不够小。

## ③-1 卡（2026-11-28 落稿）

**记录动作电位时，电极热噪声比放大器噪声大**

规格表上的数只是放大器这一项。记录噪声里还有**电极热噪声（thermal noise）**：电极电阻里电荷的热运动产生的电压噪声，电极选定后由物理规律确定²。两者互不相关，按平方相加，大的一方决定总噪声。

Intan 只给一个噪声值，下面改用分频段给值的 Neuropixels 1.0⁴。以一支 1 MΩ 的电极为例，在动作电位频段（0.3–10 kHz）：
- 放大器噪声：**5.9 µVrms**⁴
- 电极热噪声：约 **12.9 µV**（自算，37 °C）
- 两者合计约 14.2 µV，只比电极单独存在时大 10%（自算）

信号本身：大鼠海马的实测中，电极 50 µm 以内的神经元，动作电位幅度 ≥ **60 µV**⁵。

所以记录动作电位时，换一颗更安静的芯片，总噪声改善有限。

> ²Friis HT. (1944)，p.420：电阻的均方噪声电动势为 4kTR·df。⁴Neuropixels 1.0 probe datasheet，p.3。⁵Henze DA, et al. (2000). J Neurophysiol 84:390–400.
> 笔记：热噪声按 √(4kTRB) 自算，T = 310 K，R = 1 MΩ，B = 9.7 kHz（与 Neuropixels AP 频段一致）。此前讲解中的 9.9 µV 用的是 5.7 kHz 带宽，与 Neuropixels 频段不一致，已改为 12.9 µV。1 MΩ 是示例阻抗，Neuropixels 自身电极阻抗更低，卡中写「以一支 1 MΩ 的电极为例」。

## ③-2 卡（2026-11-28 落稿）

**记录 LFP 时，放大器噪声反超电极热噪声**

同一支 1 MΩ 电极，换到 LFP 频段（0.5–500 Hz）：
- 放大器噪声：**9.2 µVrms**⁴
- 电极热噪声：约 **2.9 µV**（自算）

频段变窄了，放大器噪声反而升高。原因就是前面讲的两段噪声谱：电极热噪声是白噪声，随带宽变窄而下降；放大器在低频有 1/f 噪声，频率越低越强。

所以记录 LFP 时，芯片的低频噪声才是需要重点比较的指标。

> 笔记：2.9 µV 假设电极阻抗在各频率均为 1 MΩ；实际微电极低频阻抗更高，热噪声会更大，2.9 µV 为下限。LFP 信号幅度暂无读到原文的出处，未写。

## ④ 卡（2026-11-28 落稿）

**用这个数之前，先做三件事**

1. **只比较同一频段的噪声值。** 噪声值和频段绑定：Intan 只给一个值，Neuropixels 分频段给值，频段不同的数不能直接比较。
2. **先确定要记录什么信号，再决定先换什么。** 记录动作电位时，主要看电极（阻抗高低、离神经元多近）；记录 LFP 时，主要看芯片的低频噪声。
3. **自己测一次。** 把放大器输入接到参考端或地，记录输出，再按自己使用的频段算 rms。这样测到的是整条链路。例如 Intan 规格书写明，用普通 CMOS 接口、ADC 高速采样时，放大器噪声会升高至少 10%–30%¹。

第 3 步不是电源短路：回路里没有电压源，所以不会产生电流。需要注意的是静电，接线前先释放身上的静电¹。

> ¹Intan RHD2000 datasheet，p.12（CMOS 接口）、p.28（静电，人体可积累超过 1000 V）。
> 笔记：TDT 3 µVrms（300–3000 Hz）原文未在本会话读到，按新规则不进卡。

## 局限卡（2026-11-28 落稿）

**规格表上的噪声值，没有算进环境干扰**

这个值是在输入接地、外面什么都不接的条件下测出来的。实际记录时，环境里的电磁干扰（例如 50/60 Hz 工频干扰）会通过电极和导线进入信号，这部分不包含在输入参考噪声里。
