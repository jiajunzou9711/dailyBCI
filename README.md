# DailyBCI

DailyBCI 是一个脑机接口学术内容工作区，包含论文筛选与解读、知识库维护、小红书图卡生产、内容数据看板，以及脑机接口外设综述项目。

## 主要入口

| 任务 | 权威入口 |
|---|---|
| 日报、专题和知识库 | `.claude/skills/dailybci/SKILL.md` |
| 通用写作与核查规则 | `AGENTS.md` |
| DailyBCI 图卡成品 | `output/` |
| 内容数据看板 | `dashboard/index.html` |
| 外设综述当前状态 | `脑机接口综述for_涵之/项目进度.md` |
| 外设综述写作规则 | `脑机接口综述for_涵之/写作与生产规范.md` |

## DailyBCI

DailyBCI 默认围绕一篇重要论文制作中文小红书图卡。常用工作模式包括：

- 日报：检索近期论文、对照知识库、深读主论文、核查事实并制作图卡。
- 知识库：把里程碑论文整理进结构化 Markdown 库。
- 专题：围绕一个长期主题制作多卡深度内容。

X thread 默认不产出。每期最终交付为图卡、小红书发布标题与话题标签、微信公众号摘要。

## 外设综述

`脑机接口综述for_涵之/` 是独立的长期写作项目。该目录将正文、稳定写作规范、实时进度和六项功能证据库分开维护。进入项目时按以下顺序读取：

1. `项目进度.md`
2. `写作与生产规范.md`
3. `资料/脑机接口外设_六项功能证据库索引.md`
4. 当前任务对应的原始证据库和核心数值核查日志

Word 与旧 Markdown 文件只作历史底稿，当前编辑对象以《项目进度.md》为准。

## 环境

- Python：用于 PDF 取图、裁图和部分图像处理。
- Node.js 与 Playwright Chromium：用于 HTML/CSS 图卡渲染。
- 浏览器：用于公开论文、监管文件和产品官方资料的核验。

首次渲染前需要安装 Chromium：

```bash
npx playwright install chromium
```

## 证据原则

- 关键数字回到原始论文或监管文件核对。
- 企业产品结构、同行评议效能和监管许可分层记录。
- 最高级、唯一性和否定性断言必须限定检索范围。
- 正文引用进入定稿前统一检查真实性、对应关系和编号顺序。完整长文分期改编时保留原编号，每期单列引用文献并核对对应关系。

成品检索见 `output/INDEX.md`；各文章目录的 `draft.md` 记录最终路径及发布状态。用户要求仅留最终图卡并完成清理后，以最终PNG目录为交付入口，避免继续引用已删的预览HTML或ZIP。
