## 解决了什么问题
与 Venkatesh 2019 同一问题、由独立团队（海德堡 Winkler 组）验证：神经元是否通过谷氨酸能突触直接把兴奋性输入送入胶质瘤细胞，并驱动肿瘤进展？

## 核心方法
在人类胶质瘤样本与异种移植中做膜片钳电生理、钙成像与在体活体成像，检测神经元→胶质瘤的谷氨酸能突触传递，并操纵 AMPA 受体信号观察肿瘤侵袭与生长。

## 关键数据
- 独立证实神经元与胶质瘤细胞间存在 **AMPA 受体介导的谷氨酸能突触**输入，产生兴奋性突触后电流。
- 突触驱动的膜去极化与钙内流促进胶质瘤细胞的侵袭性迁移与增殖。
- 阻断 AMPA 受体信号可减缓肿瘤进展。

## 为什么是 milestone
与 [[venkatesh-2019-electrical-synaptic-integration-glioma]] 背靠背发表、由独立实验室得出一致结论，把「神经元-胶质瘤真突触」从单一发现提升为可复现的确立事实。两篇共同奠定 cancer-neuroscience 电生理支柱。
