## 解决了什么问题
人类被试只能口头描述光幻视"有多大、什么颜色"，这类报告难以量化、也无法在同一被试上做大量试次。要给刺激-知觉关系建模，需要一套能在动物身上重复测量的心理物理方法。

## 核心方法
训练**恒河猴**做两项行为任务，测量单点刺激 V1 微电极时产生的知觉光斑的**大小、对比度与颜色**。物种选择的理由是猕猴视觉系统与人接近，且这条路线可参照人工耳蜗先在动物上打磨的做法。

## 关键数据
- 刺激中央视野 **5° 以内**的 V1 表征区，产生的光斑直径为 **9–26 弧分**。
- 光斑对比度为 **2.6%–10%**。
- 多数情况下光斑**比背景更暗**，并带有多种低对比度的颜色。

## 为什么是 milestone
这条线上第一份可量化、可重复的**光幻视心理物理**数据，把"光幻视是什么样"从口头描述变成可以喂进模型的输入参数。两个数字对假体设计直接构成约束：光斑只有**几十弧分**（意味着单电极承载的空间信息极有限），以及对比度只有百分之几且常为暗斑——这与"皮层刺激等于在视野里点亮像素"的直觉相反。它与 [[bosking-2017-phosphene-size-saturation]] 一起构成"光幻视大小到底由什么决定"这条问题线的两端（猕猴心理物理 vs 人类 + 皮层放大因子模型）。
