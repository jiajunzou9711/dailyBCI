## 解决了什么问题

本条目是**本子线的 milestone 抽取来源综述**(开放获取)。它系统梳理 HD-DOT 这条路线：近红外光在生物组织中弥散传播的基本原理、正向光传播建模与图像重建、系统设计上必须克服的三类挑战、以及验证策略与临床应用。

## 核心方法

综述结构分四层：
1. **理论**——光子在组织中的扩散、正向建模、Born/Rytov 微扰法、数值方法与图像重建；
2. **系统设计**——三类挑战：光电设计(动态范围)、光极与头皮的耦合及帽体设计、数据质量保证；
3. **验证**——视网膜拓扑、运动、语言三类范式，以及静息态功能连接；
4. **临床应用**。

## 关键数据

综述明确的分级(本子线的坐标系)：
- **fNIRS(单对源-探测器)** → 沿一条宽路径测血流动力学，混有脑与浅层组织。
- **多通道 fNIRS** → 拿到更多血流动力学信息，但仍不成像。
- **弥散光学地形(topography)** → 稀疏多通道重建成空间图，分辨率中等、**无深度信息**。
- **弥散光学层析(DOT)** → 空间**重叠**的测量做层析重建，得到三维图。
- **HD-DOT** → 密集规则阵列 + 多个间距上的重叠测量，图像质量进一步提高。

## 为什么是 milestone

它是这条线的**权威坐标系**：判断任何一台光学系统时，先按上面这个分级把它归位(是 topography 还是 tomography？重叠测量到什么密度？)，再看它的动态范围与通道数。这一步做完之前，"高密度""接近 fMRI"这类说法都无法核实。综述也点明了这条路线不可替代的生态位——**床旁与最小约束下的高保真功能成像**，这正是它相对 PET(电离辐射)与 fMRI(强磁场、不兼容植入器械)的结构性优势所在。
