## 解决了什么问题
熟悉环境中的空间表征被默认为稳定的。但当技术上能够**跨周追踪同一批已识别神经元**之后，这个假设第一次可以被直接检验。

## 核心方法
小鼠 CA1 的长期活体钙成像，跨数周反复在**同一个熟悉环境**中记录，并逐日追踪同一批可识别的神经元，比较各天之间位置细胞集合与位置野的重合情况。

## 关键数据
- 同一熟悉环境中，**每天激活的是一批不同的位置细胞**。
- 任意两天之间只有约 **15–25%** 的细胞重叠并保持原来的位置野。
- 尽管如此，**这一小撮稳定重叠的细胞已足以在数周里维持准确的空间表征**。
- 物种：**小鼠**。

## 为什么是 milestone
它把"表征漂移"从理论猜想变成硬实证：**电极与信噪比都正常，神经编码本身仍在变。** 这是一类与器件失效完全不同的失效模式。同时它给出了漂移速度的区域差异基准——与运动皮层的流形稳定（[[gallego-2020-long-term-stability-dynamics]]）形成两个极端，决定了固定解码器在不同脑区的可用寿命。
